This is the official API documentation for the Job Portal System. Our API provides a robust and scalable platform for connecting job seekers with employers.

## Key Features

- **User Management**: Support for Job Seekers, Employers, and Administrators.
- **Job Postings**: Create, update, and manage job listings with rich metadata.
- **Applications**: Streamlined application process with resume upload support.
- **Messaging**: Real-time communication between employers and job seekers.
- **Authentication**: Secure JWT-based authentication for all endpoints.

## Getting Started

To begin using the API, you'll need to register an account and obtain an authentication token.

1. **Register**: Use the `/auth/register` endpoint to create a new user.
2. **Login**: Use the `/auth/login` endpoint to receive a JWT token.
3. **Authorize**: Include the token in the `Authorization: Bearer <token>` header for protected routes.
